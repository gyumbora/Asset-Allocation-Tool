## 1. 이 프로그램은 무엇인가요?

- 계좌마다 보유 종목, 평단가, 현재가, 목표비중을 입력하면, 목표비중에 맞추기 위해 **얼마를 사고 얼마를 팔아야 하는지** 자동으로 계산합니다.
- 프로그램은 **내 컴퓨터 안에서만** 실행됩니다. 화면은 인터넷 브라우저에 표시되며, 입력한 계좌 정보는 모두 내 컴퓨터의 파일에 저장됩니다.
- 예외적으로 **"현재가 새로고침"** 을 누르면 종목코드(6자리 숫자)만 다음(Daum) 금융에 보내 현재가를 조회합니다. 계좌 정보나 금액은 보내지 않습니다.

## 2. 압축 풀기

1. 받으신 zip 파일을 **마우스 오른쪽 버튼**으로 클릭합니다.
2. "압축 풀기" 또는 "모두 압축 풀기..."를 클릭합니다.
3. 원하는 위치(예: 바탕화면, 문서 폴더 등)를 선택하고 "압축 풀기"를 누릅니다.
4. 압축이 풀린 폴더 안에 `run_server.bat`, `server.py`, `tool.html`, `README.md`, `accounts` 폴더가 있는지 확인합니다.

> 💡 폴더 안의 파일 이름은 바꾸지 마세요. 폴더를 통째로 다른 곳에 옮기는 것은 괜찮습니다.

## 3. Python 설치하기 (처음 한 번만)

이 프로그램은 **Python**이 컴퓨터에 설치되어 있어야 실행됩니다. 이미 설치되어 있다면 이 단계는 건너뛰어도 됩니다. 나중에 "Python was not found"라는 메시지가 보이면 이 단계로 돌아와 설치해 주세요.

1. 인터넷 브라우저에서 아래 주소로 이동합니다.
   `https://www.python.org/downloads/`
2. "Download Python 3.xx.x" 버튼을 눌러 설치 파일을 받습니다. (버전 숫자는 시기에 따라 다릅니다)
3. 받은 파일(예: `python-3.xx.x-amd64.exe`)을 더블클릭해 실행합니다.
4. 설치 화면 아래쪽의 **"Add python.exe to PATH"** 체크박스를 **반드시 체크**합니다.
5. "Install Now"를 누르고, "Setup was successful"이 보이면 "Close"를 누릅니다.

> ⚠️ **가장 중요한 부분입니다.** 이 체크박스를 체크하지 않으면 `run_server.bat`을 실행해도 "Python was not found on this PC." 메시지가 나오며 프로그램이 켜지지 않습니다.
>
> 이미 체크하지 않고 설치했다면, 설치 파일을 다시 실행해 "Modify"(또는 Repair)를 선택하고 "Add python.exe to PATH"를 체크해 주세요.

## 4. 프로그램 실행하기

1. 압축을 푼 폴더를 엽니다.
2. `run_server.bat`을 **더블클릭**합니다.
3. 까만 창(콘솔창)이 뜨고 잠시 후 인터넷 브라우저가 열리면서 `http://127.0.0.1:8765/tool.html` 주소의 화면이 나타납니다.

> 🛡️ Windows에서 보안 경고가 뜨면 "추가 정보" → "실행"을 눌러 진행하세요.

**까만 창은 닫지 말고 켜 두세요.** 이 창이 떠 있는 동안만 프로그램이 작동합니다.

> 💡 실행한 뒤 이미 이전에 켜 둔 프로그램이 있으면, 새 창은 바로 닫히고 브라우저에 기존 화면이 열립니다.

## 5. 화면 사용법

### 처음 실행했을 때

처음 실행하면 **"계좌 1"** 이라는 이름의 예시 계좌와 예시 종목 6개가 들어 있습니다. 실제 계좌 정보로 바꾸어 쓰거나, 필요 없으면 종목을 ×로 지우고 새로 입력하세요.

### 계좌 탭

- 화면 위쪽에 계좌 탭이 있습니다. 탭 안의 이름을 클릭해서 바로 고칠 수 있습니다. (최대 6글자)
- **"+ 계좌"** 를 누르면 새 계좌가 만들어집니다. 이름은 "계좌 2", "계좌 3"처럼 자동으로 붙고, 현금과 종목은 비어 있는 상태로 시작합니다.
- 탭의 **×** 를 누르면 그 계좌를 삭제합니다. 계좌 파일도 함께 삭제되므로 되돌릴 수 없습니다. 계좌가 1개만 남으면 삭제할 수 없습니다.

### 요약 카드

화면 위쪽에 7개의 카드가 있습니다.

| 카드 | 설명 |
|---|---|
| 현금 잔액 | 직접 입력합니다. |
| 추가 투자금액 | 이번에 새로 넣을 돈을 직접 입력합니다. |
| 현재 평가액 합계 | 보유 종목의 현재가 × 보유수 합계 (자동) |
| 총 자산 | 현금 + 현재 평가액 합계 + 추가 투자금액 (자동) |
| 전체 수익률 | 평가액 합계 ÷ 평단가 기준 원가 합계 - 1 (자동) |
| 순매수(+)/매도(-) 금액 | 추가주문 전체의 금액 합계 (자동) |
| 리밸런싱 후 예상 현금 | 현금 + 추가 투자금액 - 순매수 금액 (자동) |

### 종목 표

| 열 이름 | 설명 |
|---|---|
| 정렬 (▲▼) | 종목 순서를 위/아래로 바꿉니다. |
| 종목명 / 코드 | 직접 입력합니다. 코드는 6자리 숫자(예: `148070`)입니다. |
| 평단가 | 그 종목을 평균적으로 얼마에 샀는지 입력합니다. |
| 현재가 | 직접 입력하거나, "현재가 새로고침"으로 자동 조회합니다. |
| 수익률 | (현재가 ÷ 평단가 - 1)로 자동 계산됩니다. |
| 보유수 | 지금 가지고 있는 수량입니다. |
| 목표비중% | 이 종목을 전체 자산의 몇 %로 유지할지 입력합니다. 모든 종목의 합이 100%가 되어야 합니다. |
| 현재비중 | 현재 평가액 중 이 종목이 차지하는 비율입니다. (자동) |
| 추가주문수 | 목표비중에 맞추기 위해 필요한 수량입니다. 양수면 **매수**, 음수면 **매도**입니다. (자동) |
| 주문금액 | 추가주문수 × 현재가입니다. (자동) |
| 예상평가액 / 예상비중 | 주문이 모두 체결되었을 때의 평가액과 비중입니다. (자동) |
| 주문 체크 | 증권사에서 실제로 주문을 넣었을 때 체크하는 메모용 칸입니다. 체크하면 줄이 회색으로 바뀝니다. 수량이나 금액에는 영향을 주지 않습니다. |

- 표 아래 **"+ ETF 추가"** 로 종목을 추가하고, 줄 오른쪽의 **×** 로 종목을 삭제합니다. 삭제할 때는 확인 창이 한 번 뜹니다.
- 추가주문수는 **현재가가 0보다 커야** 계산됩니다. 현재가를 입력하지 않은 종목은 주문이 0으로 표시됩니다.
- 추가주문수는 목표비중 기준으로 계산되므로, 합계 주문금액이 현금보다 크면 아래의 "현금이 부족합니다" 경고가 나타납니다.

### 현재가 새로고침

1. 코드가 입력된 종목들을 **한 종목씩 차례로** 다음 금융에서 조회합니다. 버튼에는 "조회 중... (2/6)"처럼 진행 상황이 표시됩니다.
2. 조회에 성공한 줄은 약 1초 동안 굵게 강조된 뒤 원래대로 돌아갑니다. 이때 **종목명도 다음 금융에 표시된 이름으로 바뀝니다.**
3. 조회에 실패하면 서버가 최대 3번까지 다시 시도합니다. 그래도 실패한 종목은 기존 현재가를 그대로 두고, 모두 끝난 뒤 실패한 종목 목록을 알려 줍니다.

> 다음 금융의 조회 방식이 바뀌면 조회가 실패할 수 있습니다. 이때는 현재가 칸에 직접 입력해 주세요. 장 마감 후에는 종가가 현재가로 표시됩니다.

### 추가 주문 완료

표에 계산된 추가주문수를 **현재가로 모두 체결했다고 가정하고** 결과를 계좌에 반영하는 버튼입니다.

- **매수한 종목**: 보유수량이 늘고, 평단가는 기존 원가와 새로 산 금액을 합쳐 다시 계산됩니다.
- **매도한 종목**: 보유수량만 줄고 남은 수량의 평단가는 그대로 유지됩니다. 전부 팔면 평단가는 0이 됩니다.
- **현금 잔액**: 매수·매도 금액의 차이가 현금 잔액에 반영됩니다. 1주 단위로만 거래되므로 현금이 약간 남거나 모자랄 수 있으며, 그 차액도 현금에 그대로 반영됩니다. 적용 후 현금은 "리밸런싱 후 예상 현금" 카드의 금액과 같습니다.
- **추가 투자금액**: 현금에 합쳐진 뒤 0으로 초기화됩니다.
- **주문 체크**: 모두 해제됩니다.
- 현금이 부족해서 예상 현금이 마이너스이면 적용되지 않고, 부족한 금액을 알려 줍니다.

> ⚠️ 적용하면 보유수량·평단가·현금이 바로 바뀌며 **되돌릴 수 없습니다.** 적용 전에 "JSON 내보내기(백업)"로 백업 파일을 먼저 저장해 두세요.

### 경고 문구

- **"목표비중 합계가 100%가 아닙니다"**: 목표비중의 합이 100%가 아닐 때 나타납니다.
- **"현금이 부족합니다"**: 추가주문을 모두 체결하려면 돈이 모자랄 때 나타나며, 모자라는 금액이 함께 표시됩니다.

### 도움말 버튼

화면 오른쪽 위의 **❓ 도움말** 을 누르면 이 설명서가 새 탭에 텍스트로 열립니다.

### JSON 내보내기 / 가져오기

- **JSON 내보내기(백업)**: 모든 계좌 데이터를 `연금저축_리밸런싱_백업_년월일_시분초.json` 파일로 저장합니다.
- **JSON 가져오기(복원)**: 백업 파일을 불러와 현재 데이터를 **덮어씁니다.** 불러오기 전에 현재 데이터를 먼저 백업해 두세요. 백업 파일에 없는 계좌는 삭제됩니다.

## 6. 데이터는 어디에 저장되나요?

- 계좌 데이터는 압축을 푼 폴더 안의 **`accounts`** 폴더에 저장됩니다. 계좌마다 `계좌ID.json` 파일이 하나씩 생기고, 계좌 순서와 현재 선택된 탭은 `_index.json`에 기록됩니다.
- 입력하거나 버튼을 누르면 약 0.3초 뒤 자동으로 저장됩니다. 화면 아래의 "서버에 저장됨 시:분:초" 표시로 저장 여부를 확인할 수 있습니다.
- 따로 저장 버튼을 누를 필요는 없습니다.
- 서버 연결이 끊기면 화면 위에 빨간 경고가 뜨고, 그동안 입력한 내용은 저장되지 않습니다. 서버를 다시 켜고 화면을 새로고침하세요.

## 7. 프로그램 끄는 방법

까만 콘솔창을 닫거나, 창을 클릭한 뒤 **Ctrl + C** 를 누르면 됩니다. 입력한 내용은 이미 저장되어 있으므로 따로 저장할 필요는 없습니다.

## 8. 문제가 생겼을 때 (자주 묻는 질문)

**Q. `run_server.bat`을 눌렀더니 "Python was not found on this PC."라고 나와요.**
A. 3단계를 확인하세요. 설치할 때 "Add python.exe to PATH"를 체크해야 합니다. 체크하지 않았다면 Python을 다시 설치하면서 체크해 주세요.

**Q. 브라우저 화면에 "서버에 연결할 수 없습니다"라는 빨간 경고가 나와요.**
A. 까만 콘솔창이 닫혀 있는지 확인하세요. 닫혀 있다면 `run_server.bat`을 다시 더블클릭한 뒤 화면을 새로고침하세요.

**Q. 더블클릭했더니 까만 창이 바로 사라져요.**
A. 이미 프로그램이 실행 중일 수 있습니다. 이때는 브라우저에 기존 화면이 열립니다. 화면이 안 열리면 작업표시줄이나 열린 브라우저 탭을 확인해 보세요.

**Q. "현재가 새로고침"을 눌렀는데 가격이 바뀌지 않아요.**
A. 종목코드가 6자리 숫자로 맞게 입력되었는지 확인하세요. 계속 실패하면 해당 종목은 현재가 칸에 직접 입력해 주세요.

**Q. 추가주문수가 0으로만 나와요.**
A. 현재가가 입력되어 있는지 확인하세요. 현재가가 0이면 계산되지 않습니다. 목표비중 합계가 100%인지도 확인하세요.

**Q. 실수로 계좌나 데이터를 지웠어요.**
A. 백업 파일(JSON 내보내기로 만든 파일)이 있다면 "JSON 가져오기"로 되돌릴 수 있습니다. 백업이 없다면 되돌릴 방법이 없습니다.

## 9. 다른 컴퓨터로 옮기기

가장 쉬운 방법은 압축을 푼 폴더 전체(`accounts` 폴더 포함)를 USB나 클라우드로 복사해 새 컴퓨터에 두는 것입니다. 새 컴퓨터에 Python을 설치한 뒤 `run_server.bat`을 실행하면 됩니다.

폴더를 옮기기 어렵다면 "JSON 내보내기(백업)"로 파일을 만들어 옮긴 뒤, 새 컴퓨터에서 "JSON 가져오기(복원)"로 불러오세요.
